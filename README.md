# Hemo Connect

## Descrição

Frontend do Hemo Connect, plataforma que facilita o agendamento de doações,
aproxima doadores dos hemocentros e incentiva uma frequência maior de doações.

## Tecnologias

- React
- TypeScript
- TSX
- Vite
- npm

## Instalação

```bash
npm install
```

## Execução

```bash
npm run dev
```

## Build

```bash
npm run build
```
